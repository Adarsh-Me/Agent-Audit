# UI fix round: live-run header/bar, sidebar order, results overlaps, pixel headings

## 1. Double loading bar (root cause found)
`components/ui/progress.tsx`: the template's `Progress` root auto-renders its own `<ProgressTrack>` AFTER children — the live page passes a second explicit track → two stacked bars. Fix: `Progress` renders children only (its only consumer is the live page, which keeps its own `h-2.5` track). One bar remains.

## 2. Live run page: merchant title + timestamp, honest failure banner
- Backend `GET /api/audit/{run_id}`: add `merchant` (Catalog→Merchant.name), `catalog_source`, `started_at`, and `reason` (humanized abort reason, reusing `_human_abort_reason` from runs.py). Update tests.
- Live page header: merchant name as the title in bold Geist Pixel (e.g. "www.femella.in"), status chip beside it, run id demoted to small mono (still click-to-copy); **right side, small**: started date + time (e.g. "24 Aug 2026 · 09:14 IST") + live-stream badge.
- Failed banner: replace the hardcoded "AI provider reported an unrecoverable error" text with the run's actual humanized `reason` from the API (circuit breaker vs restart vs engine error now read truthfully).

## 3. Sidebar order: New Audit above Current Run
`Sidebar.tsx`: insert the Current Run group at index 1 (after the Audit group) instead of unshift — order becomes Audit → Current Run → (Verification) → Catalog.

## 4. Results page: section order + overlap fixes
- Move the **Run details** card to directly after the headline strip, i.e. above **Where agent demand landed**.
- Headline strip overlaps: grid `md:grid-cols-3` → `md:grid-cols-2 xl:grid-cols-3` with `min-w-0 break-words` on all three cells — fixes the clipped "Recoverable revenue (appears once fixes…)" text.
- `ScoreDial`: move the CI text from inside the ring (overlaps at small sizes) to a caption **below** the dial — fixes the `[48.2 – 66.9]` collision on results and delta pages.

## 5. Typography: Geist Pixel everywhere for headings, thicker + larger
- `globals.css`: `--font-heading: 'Geist Pixel', 'Martian Mono', monospace` (CardTitle already uses `font-heading`, so every card heading flips to Pixel).
- `CardTitle`: `text-base font-medium` → `text-lg font-semibold` (bigger + thicker across the app).
- Page `h1` titles: `font-pixel text-lg` → `font-pixel text-2xl font-bold`.
- Body copy stays Geist sans; all numerals/data stay Martian Mono.
