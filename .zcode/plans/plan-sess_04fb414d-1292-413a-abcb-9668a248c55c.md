# Real-store connector: audit actual Shopify stores (revised per your 6 corrections)

Paste a store URL on the home page → backend imports its public product feed → same 640-trial audit pipeline on real catalog data. Locked decisions: public `products.json` (no auth) + currency picker with labeled FX.

## Backend

### 1. `backend/app/ingest/store.py` (new)
- `normalize_store_url(raw)` — bare domain / full URL / `*.myshopify.com` / existing `/products.json` link → base URL
- `fetch_shopify_rows(base_url, store_currency, max_products, http_client=None)`:
  - **Pagination:** Shopify hard-caps `/products.json` at **30 products/request** — loop `?page=1..4` until `STORE_MAX_PRODUCTS = 100` or an empty `products` array returns
  - **Edge bot-blocking:** every GET sends a browser `User-Agent` (e.g. `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AgentAudit/1.0 (+https://github.com/Adarsh-Me/Agent-Audit)`) — bare httpx gets 403/401 from the edge
  - **Client lifecycle:** self-created `httpx.AsyncClient` is always wrapped in `async with` (injected test clients are closed by the caller); timeout 15s, follow_redirects
  - Errors: 401/403/404/login-redirect → **E210** "not a Shopify store or catalog not public"; 429 → **E211** with one 2s retry; non-JSON → E210
  - Mapping per product: **sku = `shopify-var-{variants[0].id}`** (variant-level ID lineage — collision-proof if multi-variant ingestion is ever added) · title ≤200 · `body_html` → tag-stripped description ≤2000 (W103 on truncation) · `variants[0].price` → int INR · `images[0].src` · `{base}/products/{handle}` page_url
  - **Populate `structured_data = {jsonld_present: True, fields_present: [... incl. price], price_fresh: True}`** — without this every product renders "price on request" in all 640 trials (`engine/prompts.py:52`)
- **Currency semantics:** the picker selects the **store's own primary currency** (source), default INR — `/products.json` always returns store-primary-currency prices, so the user must identify it; `STORE_FX_TO_INR = {INR 1.0, USD 83.0, EUR 90.0, GBP 105.0}` converts source→INR and every response/rupee figure carries the `[assumed FX]` label
- Reuse `validate_product_list()` + `create_upload_catalog()` unchanged (`source='upload'` → no schema migration, auto tier assignment). Extend `create_upload_catalog` with optional `merchant_name`/`store_meta` (backwards-compatible) recording store URL, platform, import time, FX on the catalog.

### 2. `backend/app/routers/stores.py` (new) + register in `main.py`
- `POST /api/stores/import` {url, store_currency: INR|USD|EUR|GBP (default INR), max_products? ≤100}
- Handler order: normalize → fetch → validate → create catalog → **`await score_catalog_and_persist(...)` synchronously inside the handler** so rich/medium/starved tiers are committed to the DB **before** the 201 returns — eliminating the race where the frontend's immediate `createAudit` reads untiered products → 201 {catalog_id, store_url, products{valid, invalid, capped_to}, store_currency, fx{rate, converted, note}}
